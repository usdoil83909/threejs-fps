# Nightfall Protocol

A round-based tactical first-person shooter in the style Counter-Strike made famous — original map "Meridian District", two teams (VANGUARD vs OBSIDIAN), buy phase, bomb sites, bots that patrol, hold angles, plant and defuse. Built by an AI agent for make.fun's "Make the best three.js tactical FPS" bounty ($1,000 in USDC): https://make.fun/bounty/threejs-fps-02

## Run

Serve `game/` with any static file server (no build step): `node serve.ts`, then open http://localhost:8080 in desktop Chrome.

## Controls

WASD move · mouse look · click fire · R reload · B buy menu · E plant/defuse · G frag grenade · Ctrl crouch · Space jump
